# Homepage Design Directions

All three directions use the confirmed Palette 00 system, Literata and Atkinson Hyperlegible Next, the same approved homepage copy, the same four-page structure, the same travel imagery, and the same 1536 by 1024 desktop viewport. They are static direction studies, not implemented pages.

## 01 Field Gateway

- **Layout:** A sparse warm-paper hero led by oversized typography. Visited Countries and Interesting Places behave as large spatial gateways rather than conventional menu buttons. About Me stays quiet. The beginning of a dark patterned second fold introduces the personal field-journal system and travel imagery.
- **Hierarchy:** Name first, two primary destinations second, personal context third.
- **Density:** Low in the hero, increasing slightly as the second fold enters.
- **Mood:** Lucid, welcoming, scholarly, and quietly distinctive.
- **Potential later motion:** Gateway labels can shift or reveal imagery on interaction without changing the information architecture.

## 02 Atlas Aperture

- **Layout:** A deep-aubergine hero pairs an oversized name block with one decisive travel-image aperture. Clear indexed navigation sits outside the conventional header pattern. A warm-paper second fold reverses the theme and introduces the two primary destinations.
- **Hierarchy:** Image and name share first position; destinations follow as editorial entries.
- **Density:** Medium, with one concentrated visual anchor and controlled supporting details.
- **Mood:** Immersive, exploratory, cinematic, and still personal.
- **Potential later motion:** The aperture can expand or shift between places while the navigation remains stable.

## 03 Open Notebook

- **Layout:** A warm-paper journal spread combines the name, destination links, image fragments, and quiet profile details in a layered composition. Navigation behaves like visible notebook tabs. A dark patterned band in the second fold creates the confirmed light-to-dark rhythm.
- **Hierarchy:** Multiple entry points coexist, but name and primary destinations remain dominant.
- **Density:** Highest of the three, with deliberate clusters rather than a uniform grid.
- **Mood:** Curious, collegiate, energetic, collected, and approachable.
- **Potential later motion:** Tabs, image fragments, and annotations can respond independently with restrained page-like transitions.

## Selection Status

Direction `03-direction-v5.png` is selected as the homepage hero calibration reference. It keeps Open Notebook's contemporary diary composition, creamy paper, mapped-line pattern, notebook navigation panels, purple journal band, and restrained coral accent. The hero implementation may recompose overlaps responsively and must use semantic HTML for text and navigation rather than rasterizing the mock.
